# Notion 数据库设计文档

## 概述
本文档描述了三年级语文学习系统在Notion中的数据库结构设计。

## 数据库列表

### 1. 词语库 (Vocabulary)

**用途：** 存储所有学习词语及其相关信息

**属性字段：**
- `词语` (Title) - 标题字段，存储词语文本
- `拼音` (Text) - 词语的拼音
- `释义` (Text) - 词语的解释
- `课程` (Select) - 所属课程
  - 选项：lesson1~lesson16, other
- `课程名称` (Text) - 课程的完整名称
- `是否新增` (Checkbox) - 标记是否为新增词语
- `词语ID` (Number) - 唯一标识符
- `创建时间` (Created time) - 自动记录
- `更新时间` (Last edited time) - 自动记录

**初始数据：** 146个词语

---

### 2. 多音字库 (Polyphones)

**用途：** 存储多音字及其不同读音

**属性字段：**
- `汉字` (Title) - 标题字段，存储汉字
- `读音1` (Text) - 第一个读音（拼音）
- `读音1释义` (Text) - 第一个读音的意思
- `读音1例词` (Text) - 第一个读音的例词
- `读音2` (Text) - 第二个读音（拼音）
- `读音2释义` (Text) - 第二个读音的意思
- `读音2例词` (Text) - 第二个读音的例词
- `读音3` (Text) - 第三个读音（可选）
- `读音3释义` (Text) - 第三个读音的意思（可选）
- `读音3例词` (Text) - 第三个读音的例词（可选）
-  `课程` (Select) - 所属课程
- 选项：lesson1~lesson16, other
- `课程名称` (Text) - 课程的完整名称
- `是否新增` (Checkbox) - 标记是否为新增内容
- `多音字ID` (Number) - 唯一标识符

**初始数据：** 32个多音字

---

### 3. 近义词库 (Synonyms)

**用途：** 存储近义词组

**属性字段：**
- `词语1` (Title) - 第一个词语
- `词语2` (Text) - 第二个词语（近义词）
- `课程` (Select) - 所属课程
- 选项：lesson1~lesson16, other
- `课程名称` (Text) - 课程的完整名称
- `是否新增` (Checkbox) - 标记是否为新增内容
- `来源` (Text) - 标记来源（如"课文"）
- `近义词ID` (Number) - 唯一标识符

**初始数据：** 62组近义词

---

### 4. 反义词库 (Antonyms)

**用途：** 存储反义词组

**属性字段：**
- `词语1` (Title) - 第一个词语
- `词语2` (Text) - 第二个词语（反义词）
- `反义词ID` (Number) - 唯一标识符
- `课程` (Select) - 所属课程
 - 选项：lesson1~lesson16, other
- `课程名称` (Text) - 课程的完整名称

**初始数据：** 42组反义词

---

### 5. 用户表 (Users)

**用途：** 存储用户信息

**属性字段：**
- `用户名` (Title) - 用户登录名
- `显示名称` (Text) - 用户显示名称
- `用户ID` (Text) - 唯一标识符（UUID）
- `密码哈希` (Text) - 加密后的密码（使用bcrypt）
- `角色` (Select) - 用户角色
  - 选项：student（学生）, teacher（教师）
- `创建时间` (Created time) - 注册时间
- `最后登录` (Date) - 最后登录时间
- `总学习时长` (Number) - 累计学习时长（秒）
- `学习天数` (Number) - 累计学习天数

---

### 6. 学习记录 (Learning_Records)

**用途：** 记录用户的学习进度和结果

**属性字段：**
- `记录ID` (Title) - 记录的唯一标识符
- `用户` (Relation) - 关联到用户表
- `学习类型` (Select) - 学习模式
  - 选项：vocabulary（词语认读）, dictation（纸笔默写）, polyphone（多音字）, synonym（近义词）, antonym（反义词）
- `项目ID` (Number) - 学习项目的ID
- `项目类型` (Select) - 项目类型
  - 选项：vocabulary, polyphone, synonym, antonym
- `是否掌握` (Checkbox) - 是否掌握该项目
- `学习时间` (Date) - 学习的时间
- `课程` (Select) - 所属课程（仅词语相关）
- `创建时间` (Created time) - 记录创建时间

---

### 7. 练习会话 (Practice_Sessions)

**用途：** 记录每次练习的整体情况

**属性字段：**
- `会话ID` (Title) - 会话唯一标识符
- `用户` (Relation) - 关联到用户表
- `学习类型` (Select) - 练习模式
- `课程` (Select) - 练习的课程范围
- `开始时间` (Date) - 练习开始时间
- `结束时间` (Date) - 练习结束时间
- `用时` (Number) - 练习用时（秒）
- `总题数` (Number) - 总题数
- `正确数` (Number) - 正确题数
- `错误数` (Number) - 错误题数
- `正确率` (Number) - 正确率（百分比）
- `创建时间` (Created time) - 记录创建时间

---

## 数据关系

```
Users (用户表)
  ├── Learning_Records (学习记录) - 一对多
  └── Practice_Sessions (练习会话) - 一对多

Vocabulary (词语库) ─┐
Polyphones (多音字库) ├─ 通过 项目ID 和 项目类型 关联到 Learning_Records
Synonyms (近义词库)   ├─ (非直接关联，通过ID匹配)
Antonyms (反义词库) ──┘
```

## 索引建议

为提高查询性能，建议在以下字段上建立过滤器/视图：

### 词语库视图
- 按课程分类
- 新增词语
- 按拼音排序

### 学习记录视图
- 按用户分组
- 按学习类型分类
- 未掌握的项目
- 最近学习记录

### 练习会话视图
- 按用户分组
- 按日期排序
- 低正确率会话（< 60%）

## 注意事项

1. **数据同步：** 所有学习记录实时写入Notion数据库
2. **性能优化：** 使用缓存机制减少Notion API调用
3. **数据备份：** 定期导出Notion数据库作为备份
4. **隐私保护：** 密码使用bcrypt加密，不存储明文
5. **API限流：** 注意Notion API的调用限制（每秒3个请求）
